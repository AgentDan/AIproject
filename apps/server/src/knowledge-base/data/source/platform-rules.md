# База знаний (пример для RAG)

## Команды движения
- Фразы вроде «сдвинь вправо», «move right» относятся к перемещению выбранного объекта по оси X в положительную сторону.
- «Вверх» / «up» увеличивает координату Y.

## Материалы и цвет
- Запрос «сделай красным» меняет материал объекта на красный оттенок в MVP-логике сцены.

## GLTF / экспорт
- Команды «export», «скачать сцену» инициируют подготовку GLB для скачивания на стороне Scene Modules.
